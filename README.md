# proctune

A console program that turns running processes into sound

PID - pitch

Name length - volume

CPU load - arpeggiator

RAM - waveform

# nettune

A console program that turns network traffic into sound

Port - pitch

Traffic - volume

Packets per second - arpeggiator

Protocol - waveform
