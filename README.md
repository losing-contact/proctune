# proctune

A console program that turns running processes into sound

PID - pitch

Name length - volume

CPU load - arpeggiator

RAM - waveform

# nettune

A console program that turns network traffic into sound

```sudo setcap cap_net_raw,cap_net_admin=eip (readlink -f .venv/bin/python)```


Port - pitch

Traffic - volume

Packets per second - arpeggiator

Protocol - waveform

# disctune

A program that goes through all the files on a mounted partition and turns their bytes into sound.

Chunk contents (4096 bytes) - waveform and volume

Chunk checksum (CRC32) - small pitch shift

File name - base pitch

File size - how many chunks are played
