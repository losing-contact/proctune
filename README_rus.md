# proctune

Консольная программа, которая превращает запущенные процессы в звук.

PID - высота тона

Длинна имени - громкость

CPU загрузка - арпеджиатор

RAM - форма волны

# nettune

Консольная программа, которая превращает сетевой трафик в звук

```sudo setcap cap_net_raw,cap_net_admin=eip (readlink -f .venv/bin/python)```


Порт - высота тона

Объём трафика - громкость

Пакетов в секунду - арпеджиатор

Протокол - форма волны


# disctune

Программа, которая проходится по всем файлам в смонтированном разделе и преобразует их байты в звук.

Содержимое куска (4096 байт) - форма волны и громкость

Контрольная сумма куска (CRC32) - небольшой сдвиг высоты

Имя файла - базовая высота звука

Размер файла - сколько кусков сыграется
